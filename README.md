# PAPAPA IQ KEIBA

**Ver3.0.0** — プロ仕様AI競馬新聞 UI

AIロジック（指数・思考・買い目）は Ver2.0.0 を維持し、**AI分析ページの表示のみ**を新聞レイアウトへ大幅強化しました。

## AI分析ページ構成

1. 総合評価（カウントアップ / 信頼度バー）
2. 展開予想（コース図 + 脚質レーン）
3. 印（◎○▲△☆× + 理由）
4. 注目馬（危険=赤 / 穴=緑 / 鉄板=青）
5. 指数ランキング（クリックで詳細）
6. 能力比較グラフ（レーダー / 棒 / 折線 / 円）
7. 脚質分布
8. レースタイムライン
9. 能力バー（アニメーション）
10. 買い目タブ（券種 × 本命/バランス/穴狙い/AI対抗）
11. AIコメント

## 変更ファイル

- `analysis.html` … 新聞レイアウト
- `style.css` … Ver3.0.0 新聞UI / レスポンシブ
- `js/analysis.js` … 描画・グラフ・アニメーション
- `js/config.js` / `data/settings.json` / `README.md` / `ROADMAP.md`

※ `ai-engine.js` / `thinking-engine.js` 等の予想ロジックは変更していません。

## 確認方法

```bash
python -m http.server 5500
```

1. レース詳細 → AI分析
2. 新聞レイアウトの各セクションとアニメーションを確認
3. 指数表の行クリックで詳細表示
4. 買い目タブの切替を確認
5. スマホ幅でもレイアウトが崩れていないことを確認
